# DeepSentinel Progress Report

## Research Question

Can image dataset ownership verification for retrieval-augmented image
generation survive an attacker who filters visible key-bearing sentinel images?

## Selected Idea

DeepSentinel replaces visible random key images with distribution-preserving
latent sentinels. The sentinel is not a text-bearing image. It is an
in-distribution image whose retrieval embedding is aligned with a secret trigger.

## Pilot Result

In a synthetic clustered retrieval benchmark:

- Visible-key sentinels are removed immediately by a text-key filter.
- Hidden outlier sentinels are removed by local-density filtering with low
  collateral damage.
- DeepSentinel sentinels survive through the tested density filters because they
  live in dense normal regions.

Figure: `to_human/h1_synthetic_tradeoff.svg`.

## Why This Could Be Publishable

The paper has one clear tension: dataset owners need black-box ownership
evidence, while attackers can preprocess away obvious canaries. DeepSentinel
turns filtering into a measurable collateral-damage tradeoff.

## Next Step

Run the same evaluation with real CLIP embeddings on MS-COCO and Product-10K,
then test whether the trigger retrieval survives inside an RAIG pipeline.
